# FT-Transformer Classifier

Clasificador robusto basado en FT-Transformer para comportamiento lector.

## Estructura
- models/: Implementación del modelo FT-Transformer
- utils/: ETL, métricas, visualizaciones
- configs/: Configuraciones por grupo
- outputs/: Resultados y artefactos

## Ejecución
```bash
python main.py --config configs/config_adultos.json --paths configs/paths_adultos.json
```

## Requisitos
Ver `requirements.txt`.
